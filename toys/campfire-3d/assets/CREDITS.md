# アセットの出典

すべて [Poly Haven](https://polyhaven.com/) のアセット（CC0 / パブリックドメイン）。
容量を抑えるため、テクスチャは 512px 程度に縮小している（モデルの .gltf は画像のファイル名だけ書き換えた）。

## 3D モデル（`models/`）

| フォルダ | 元のアセット | 使いみち |
| --- | --- | --- |
| `stone_fire_pit` | [Stone Fire Pit](https://polyhaven.com/a/stone_fire_pit) | 焚き火を囲む石 |
| `tree_stump_01` | [Tree Stump 01](https://polyhaven.com/a/tree_stump_01) | 横の切り株 |
| `wooden_axe_02` | [Wooden Axe 02](https://polyhaven.com/a/wooden_axe_02) | 薪の山のそばの斧 |
| `rock_moss_set_01` | [Rock Moss Set 01](https://polyhaven.com/a/rock_moss_set_01) | まわりに散らした岩 |

## テクスチャ（`textures/`）
